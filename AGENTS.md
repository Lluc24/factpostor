# Agent Instructions

## Commit Co-Author Policy

All commits made in this repository — including those made by AI agents or automated tools — must include the following co-author as a trailer:

```
Co-authored-by: Lluc Santamaria Riba <lluc.santa@gmail.com>
```

This trailer must be added to the commit message body, separated from the rest of the message by a blank line, for example:

```
Fix bug in scoring logic

Co-authored-by: Lluc Santamaria Riba <lluc.santa@gmail.com>
```

If a commit already includes other co-authors, add this trailer as an additional line rather than replacing existing ones.
